# Repository instructions

Work on any manuscript fragment is incomplete until it is present in the
relevant TeX source, the canonical `manuscript/manuscript.pdf` has been
rebuilt from that source, and the affected pages together with the preceding
and following pages have been visually inspected. Never treat another PDF
copy as canonical and never report completion while duplicate PDF outputs
disagree.

The manuscript master is `manuscript/manuscript.tex`. Run the documented
build command from the repository root; its output-directory option writes
the canonical output to the manuscript directory automatically.
