# Repository instructions

Work on any manuscript fragment is incomplete until the fragment is present
in the relevant `.tex` source, the canonical PDF has been rebuilt from that
source, and the affected PDF pages plus the preceding and following pages
have been visually inspected. Never report a manuscript stage as complete
based only on source changes, tests, build exit status, or an unverified PDF
path.

The manuscript master is `manuscript/manuscript.tex`. Run the documented
build command from the repository root; the canonical generated output is
the root-level `manuscript.pdf`.
